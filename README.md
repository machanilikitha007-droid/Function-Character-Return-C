# Function Returning a Character in C

A simple C program that demonstrates a function returning a character value
based on the marks entered by the user.

## File

character_function.c

## Concepts Used

- Function definition
- Function parameters
- Character return value
- Function call
- if-else if-else

## How to Run

gcc character_function.c -o character_function
./character_function

## Sample Output

Enter marks: 82
Grade = B
